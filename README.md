# Blend English

文単位で土台言語と学習言語をランダムに混ぜ、文脈から意味を取るための多言語ミックスリーダーです。

## v3 主な機能
- 文単位ランダム混在
- 0〜100%を読みながら即時変更
- タップで対訳へ切替 + その場の吹き出し
- 18言語
- 見出し・段落・画像をできるだけ保持した貼り付け
- 話者 / 丁寧さ / 相手 / 補足を翻訳指示へ反映
- 翻訳スタイル（自然 / 忠実 / 学習者向け）
- CEFR / 英検相当レベル
- TTS読み上げ
- 保存表現 / 履歴
- 対訳確認回数から次のミックス率を提案
- PWA / manual.html

## 翻訳
対応するデスクトップChromeでは組み込みTranslator APIを利用できます。iPhoneなどではChatGPT用指示文を生成し、JSONを貼り戻す方式を利用します。秘密のAPIキーを公開GitHubへ埋め込みません。
